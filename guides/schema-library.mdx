---
title: Schema library
description: "Default Galya schemas for fashion, travel, hospitality, tech, watches, trading cards and video games. Use one as-is or adapt it: a schema is a prompt the model answers for every item."
---

The model is promptable. A [schema](/guides/schemas) is the prompt: a set of questions, each with its options, that the model answers for every item from its image and text. Change the questions and you change what Galya reads and ranks on, in any domain.

These default schemas cover common domains. Use one as-is, add your own questions (up to 64), or edit the options. Each edit makes a new content-addressed schema, and the old one keeps working.

| Domain | For | Schema |
| --- | --- | --- |
| [Fashion and apparel](#fashion-and-apparel) | Clothing, shoes, bags, accessories | `galya-commerce-v3` |
| [Travel](#travel) | Destinations, tours, packages, experiences | [`travel`](#travel) |
| [Hospitality](#hospitality) | Hotels, rentals, restaurants | [`hospitality`](#hospitality) |
| [Tech and electronics](#tech-and-electronics) | Phones, laptops, audio, wearables, smart home | [`tech`](#tech-and-electronics) |
| [Watches](#watches) | Mechanical, quartz and smart watches | [`watches`](#watches) |
| [Trading cards](#trading-cards) | Singles, sealed product, graded slabs | [`trading-cards`](#trading-cards) |
| [Video games](#video-games) | Games, DLC, bundles | [`video-games`](#video-games) |

Send a schema by id, or send its definition inline on any item or user call. Galya stores an inline definition the first time and returns its id as `schema_id`:

```bash
curl https://api.galya.io/v1/item \
  -H "X-API-Key: $GALYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "schema": { "name": "watches", "base": null, "questions": [ ... ] }, "items": [ ... ] }'
```

## Fashion and apparel

Clothing, shoes, bags, accessories. Send it by id. Its 219 fields include `color`, `product_family`, `pattern` and `silhouette`.

```json
{ "schema": "galya-commerce-v3" }
```
