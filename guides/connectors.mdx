A connector pulls products from a source you connect (a store, a CMS) into your catalog, so you don't have to send them yourself with [`POST /v1/item`](/guides/items). Synced products show on [Catalog](https://app.galya.io/catalog).

<RequestExample>

```bash
curl https://api.galya.io/v1/connectors \
  -H "X-API-Key: $GALYA_API_KEY"
```

</RequestExample>

## Set one up

1. `GET /v1/connectors/registry` lists the sources you can connect. `GET /v1/connectors/registry/{publicId}` describes one, including the settings it needs.
2. `POST /v1/connectors` creates a connection for the workspace.
3. `POST /v1/connectors/{connectorId}/test` checks it.
4. `POST /v1/connectors/{connectorId}/sync` pulls products in. The sync runs in the background; watch [Catalog](https://app.galya.io/catalog).

`PATCH` and `DELETE /v1/connectors/{connectorId}` update or remove a connection.

Need a source that isn't listed? `POST /v1/connectors/requests` asks for it.
