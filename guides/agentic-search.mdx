---
title: Agentic search
description: "Let outside AI agents search, recommend and rerank your catalog under a policy you control, with scoped agent keys and a manifest of what agents may do."
api: "POST /v1/agentic-search/search"
---

Agentic search is the one endpoint an outside AI agent (a shopping assistant, an LLM tool) is allowed to call. You turn it on for the workspace, choose which operations it may run and how much it may return, and issue agent keys (`galya_ag_`). An agent key cannot call the rest of the API.

## Set it up

1. `PUT /v1/agentic-search/config` turns it on and sets the policy: allowed operations, allowed catalog domains, the maximum results and traversal depth. Use the workspace secret.
2. `POST /v1/agentic-search/keys` issues an agent key. `GET` lists keys, `DELETE /v1/agentic-search/keys/{keyId}` revokes one.
3. Give the agent `GET /v1/agentic-search/manifest`: a machine-readable description of what it may call under your policy.

## Call it

<ParamField body="op" type="string" required>
  `search`, `recommend`, `rerank`, `get_entity` or `traverse`, as the policy allows.
</ParamField>

<ParamField body="user_id" type="string">
  The shopper. Required for `search`, `recommend` and `rerank`.
</ParamField>

<ParamField body="candidate_ids" type="string[]">
  Item ids. Required for `rerank`.
</ParamField>

<ParamField body="entity_id" type="string">
  An item id. Required for `get_entity`.
</ParamField>

<ParamField body="seed_entity_id" type="string">
  Starting item. Required for `traverse`.
</ParamField>

<ParamField body="domain" type="string">
  Catalog slice, when the policy restricts domains.
</ParamField>

<ParamField body="limit" type="integer">
  Capped by the policy's maximum results.
</ParamField>

<RequestExample>

```bash
curl https://api.galya.io/v1/agentic-search/search \
  -H "X-API-Key: $GALYA_AGENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{"op": "recommend", "user_id": "shopper_1", "limit": 10}'
```

</RequestExample>

<Note>
  If agentic search is off for the workspace, calls return `403 agentic_search_disabled`. Turn it on with the config call first.
</Note>
