title: Quickstart
description: "Galya API quickstart: upsert catalog items, wait for their readouts, record a shopper's interactions, and get a taste-ranked list with reasons, in four curl calls."
---

You need a workspace and its secret key from [API keys](https://app.galya.io/api-keys). Don't have a workspace yet? Email [hello@galya.io](mailto:hello@galya.io) about a [pilot](https://www.galya.io/pilot/).

```bash
export GALYA_API_KEY="galya_sk_..."
```

The example items are apparel, so every call below names `"schema": "galya-commerce-v3"`, the default schema for fashion and apparel. For travel, hospitality, tech, watches, trading cards or video games, pick that domain's schema from the [schema library](/guides/schema-library) instead, or [write your own questions](/guides/schemas).

## 1. Send items

An item is one product (or video, or look): your id, a title, the text and image the model reads, and any metadata you want back. Up to 100 per call.

```bash
curl https://api.galya.io/v1/item \
  -H "X-API-Key: $GALYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "schema": "galya-commerce-v3",
    "items": [
      {
        "id": "sku_wrap_dress",
        "title": "Black wrap midi dress",
        "text": "Wrap silhouette, crepe, midi length.",
        "image_url": "https://cdn.example.com/wrap-dress.jpg",
        "metadata": { "product_id": "1001", "price": 129 }
      },
      {
        "id": "sku_ankle_boot",
        "title": "Leather ankle boot",
        "image_url": "https://cdn.example.com/ankle-boot.jpg",
        "metadata": { "product_id": "1002", "price": 189 }
      }
    ]
  }'
```

The call returns `202` right away. The model reads each item in the background:

```json
{
  "schema_id": "galya-commerce-v3",
  "items": [
    { "id": "sku_wrap_dress", "status": "pending" },
    { "id": "sku_ankle_boot", "status": "pending" }
  ]
}
```

## 2. Wait for readouts

A readout usually lands within half a minute. List what is still pending:

```bash
curl "https://api.galya.io/v1/item?schema=galya-commerce-v3&status=pending" \
  -H "X-API-Key: $GALYA_API_KEY"
```

When the list is empty, every item is `ready`. To see what the model read for one item — a probability per option for each field, such as `color`, `silhouette` and `product_family` — fetch it:

```bash
curl "https://api.galya.io/v1/item/sku_wrap_dress?schema=galya-commerce-v3" \
  -H "X-API-Key: $GALYA_API_KEY"
```

## 3. Record interactions and rank, in one call

`POST /v1/user` takes a shopper's interactions and a ranking request together. Interactions are applied before the ranking, so the result already reflects them. Tags are plain language.

```bash
curl https://api.galya.io/v1/user \
  -H "X-API-Key: $GALYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "shopper_1",
    "schema": "galya-commerce-v3",
    "interactions": [
      { "id": "evt_1", "item_id": "sku_wrap_dress", "tag": "liked" }
    ],
    "rank": { "limit": 10 },
    "include": ["taste"]
  }'
```

```json
{
  "user_id": "shopper_1",
  "schema_id": "galya-commerce-v3",
  "interactions": [
    { "id": "evt_1", "item_id": "sku_wrap_dress", "tag": "liked", "read_as": "like", "status": "recorded" }
  ],
  "ranked": [
    { "item_id": "sku_ankle_boot", "score": 0.21, "reasons": [{ "field": "color", "option": "Black", "lift": 0.18 }] }
  ],
  "taste": { "summary": "Black, Wrap, Midi", "evidence": 1, "fields": [] },
  "meta": { "state_source": "model" }
}
```

`rank` with no `item_ids` recommends from the whole catalog. Pass `item_ids` to rerank your own list, or `query` to search.

## 4. Rerank a page

Most storefronts already have a list to show: a collection page, search results, a carousel. Send it as `item_ids` and render the order Galya returns:

```bash
curl https://api.galya.io/v1/user \
  -H "X-API-Key: $GALYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "shopper_1",
    "schema": "galya-commerce-v3",
    "rank": { "item_ids": ["sku_ankle_boot", "sku_wrap_dress"], "limit": 2 }
  }'
```
