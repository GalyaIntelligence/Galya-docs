Galya keeps a catalog of things you can recommend, a record of who engaged with them, and a way to query that taste. You do this in a workspace. The [dashboard](https://app.galya.io) is where you watch the catalog and copy keys. The API is how your app writes and queries it.

The interactive examples in these docs send requests to the [development API](/development-api).

## What you work with

| Module | What it is | Where you see it |
| --- | --- | --- |
| Entities | People, products, brands, and other things you score | [People](https://app.galya.io/people) and [Catalog](https://app.galya.io/catalog) |
| Contents | The text or media attached to an entity | Catalog, after you index |
| Links | A record that one entity is about another | Built on [Get started](https://app.galya.io/get-started), then visible as taste on People |
| Query | Search, recommend, and rerank | Get started, step “Query taste” |
| Models | How a query scores the catalog | Chosen on the request; results show on Overview and Catalog |
| Audience types | Groups of people with similar taste | [Audience types](https://app.galya.io/audience-types) |
| Agentic search | Let an outside agent query under a policy you set | API |
| Connectors | Bring a catalog in from a source you connect | Lands in Catalog |

## A first loop

1. Open [Get started](https://app.galya.io/get-started) and copy the workspace secret from **Copy your workspace keys**.
2. Index one catalog item and create a person. See [Quickstart](/quickstart).
3. Link that person to the item, then search or recommend.
4. Open [Catalog](https://app.galya.io/catalog) and [People](https://app.galya.io/people) to see what landed.
