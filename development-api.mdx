---
title: Development API
description: "Every Galya docs playground and example calls the development API at dev.api.galya.io. Use it to try requests, and never send production traffic there."
---

Every interactive playground in these docs sends the request to:

```
https://dev.api.galya.io
```

The API reference uses the same host. You will see the full URL on each endpoint. There is no other host to pick in the playground.

Use a workspace secret from [API keys](https://app.galya.io/api-keys). The playground stores that header in your browser for the session.

<Note>
  Point examples, scripts, and the playground at this host while you are trying the API. Do not send production traffic here.
</Note>
